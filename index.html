    Principles

    Classless

    Elements are the API. <article> is a card, <menu> is a toolbar, <aside> is a panel. State comes from ARIA, not class names.

    Automatic flex

    Every container is a column flex box, so gap replaces margin collapsing. Cards collect into a grid on their own, and rows — nav, menu, button groups — are decided by :has(), not by you.

    Neo-brutal

    Hard borders, hard offset shadows, inverted hover, and a press-down active state. All borders and paddings are small.

    Squircles

    Never a plain round. Only controls and cards get corner-shape: squircle. Tables, quotes, and images stay sharp. Browsers without support fall back to a small plain radius.

    Two colors

    Swamp paints, everything else is an oklab mix. The nine accents are text-only — never a background.

    • --snowy #c1cebf
    • --swamp #1f311d

    App-ready

    Sidebars, inspectors, dialogs, toolbars, switches, and a full-height chat or canvas surface. <svg> and <canvas> size themselves.

    One flex gap spaces every block. Headings add a single extra beat above and nothing below, so a heading always reads as belonging to what follows. Paragraphs carry no margins at all.

    A heading after content

    No heading carries padding, except h2, which has a rule under it. h1 gets a short lemon bar.

    Inline

    A link, strong, em, mark, del, code, Ctrl + K, H2O, E = mc2, and CSS.

    Flex items don't collapse margins, so the gap owns the rhythm and headings only lean on it.

    Gotchas

    • Containers are columns, not wrapping rows. Prose belongs in <p> — loose text next to an inline tag becomes its own flex item.
    • Squircles need corner-shape (Chromium 139+). Elsewhere the radius is small and plain, by design. Nothing is pill-shaped.
    • h2 is the only heading with a border; h1 is the only heading with a bar.
    • Put button groups in <menu> so they get their own row.
